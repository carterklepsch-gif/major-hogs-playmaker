FROM BLANK FIELD TO YOUR PLAYBOOK

You’re the coordinator.

  1. Set the formation. In Move mode, drag the eight named circles. Gray X marks are optional opponents you can also move.
  2. Draw a job. Select a player, choose Route, Run, Block or Motion, then tap the field at each bend. Press Finish path. For a snap or pass, select the player sending the ball.
  3. Run it. Press Run play to watch the movements. Pause, scrub the timeline or slow it down. Reset returns everyone to their starting positions.
  4. Explain it. Write each player's assignment in the workshop. Add when to call the play and how it works.
  5. Build your collection. Changes save automatically in this browser. Duplicate to make a counter; back up to keep a portable copy. Print / PDF exports the current play and all eight assignments.

Arrow keys nudge the selected player in Move mode when you’re not typing. Escape cancels a path. Undo and Redo cover your edits. This is a drawing tool; it does not judge formation or receiver eligibility.
